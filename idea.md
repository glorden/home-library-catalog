# Проект: Каталог домашней библиотеки

## Идея

Создать open-source каталог домашней библиотеки с упором на
**автоматическую каталогизацию бумажных книг**, особенно советских и
старых изданий без ISBN.

Главная ценность проекта --- не хранение книг, а максимально быстрое
создание качественной библиографической записи.

## Основной сценарий

1.  Пользователь фотографирует:
    -   обложку;
    -   титульный лист;
    -   оборот титульного листа.
2.  Система отправляет изображения в выбранную пользователем AI-сервис.
3.  AI возвращает структурированные данные.
4.  Пользователь проверяет и исправляет их.
5.  После подтверждения запись сохраняется.

> AI **никогда не записывает данные в базу автоматически**.

## Стек

-   Backend: FastAPI
-   База данных: PostgreSQL
-   ORM: SQLAlchemy / SQLModel
-   Миграции: Alembic
-   Frontend: Jinja2 + htmx + Tailwind CSS
-   Инфраструктура: Docker Compose, nginx, Certbot
-   Хранение фотографий: локальный volume
-   Репозиторий: GitHub

## Почему Jinja2 + htmx

Большая часть логики находится на сервере (OCR, AI, поиск,
каталогизация).

htmx позволяет получать готовые HTML-фрагменты от FastAPI без React и
сложного JavaScript.

## Модель данных

### editions

Библиографическая запись издания.

### copies

Конкретный физический экземпляр.

### photos

Отдельная таблица фотографий (обложка, титул, оборот титула, автографы и
т.д.).

## Добавление книги

Фото → AI → форма подтверждения → сохранение.

## AI

Не привязывать проект к одной модели.

Создать абстракцию `ExtractionService`.

Реализации могут быть разными:

-   Claude
-   ChatGPT/OpenAI
-   Gemini
-   локальная LLM
-   другие совместимые сервисы

Идея проекта --- **пользователь сам выбирает**, каким AI пользоваться.

Возможные варианты:

-   ввод собственного API-ключа;
-   выбор провайдера в настройках;
-   единый интерфейс независимо от выбранной модели.

Таким образом проект не зависит от одной компании.
