## [1.1.0] - 2026-08-03

### Добавлено
- Маршрутизация вызовов AI-провайдера через SOCKS5-туннель (Шаг 9) — обход блокировки прод-VPS (Россия) у провайдеров, блокирующих по IP (Groq); не помогает при блокировке по аккаунту/проекту ключа (Gemini) — см. ARCHITECTURE.md, «Шаг 9», и DEPLOY.md
- Явное подтверждение после сохранения настроек AI-провайдера
- Индикация состояния «Распознаём...» на кнопке при отправке формы распознавания; реальные логи приложения (`logger.info` теперь долетают — раньше root-логгер без хендлеров молча их ронял)

### Изменено
- Мобильный UX загрузки фото: доступ к галерее, фото титульного листа стало необязательным

### Исправлено
- Service Worker: офлайн-фолбэк теперь ограничен только GET-навигациями, не перехватывает остальные запросы
- Временный подъём `EXTRACTION_MAX_TOKENS` с 4096 до 6000 откачен обратно — у Groq квота считается по запрошенным токенам, а не по фактически использованным, подъём сразу упирался в `413 rate_limit_exceeded`

## [1.0.0] - 2026-07-26

MVP: каталог домашней библиотеки с AI-распознаванием.

### Добавлено
- Каркас репозитория, Docker Compose, CI (Шаг 1)
- Модель данных и CRUD для изданий/экземпляров (Шаг 2)
- Загрузка фото обложки с ресайзом и удалением EXIF (Шаг 3)
- AI-извлечение библиографических данных с фото — Claude или OpenAI-совместимые провайдеры (Groq/Gemini/Ollama/LM Studio), обязательное подтверждение перед сохранением (Шаг 4)
- Аутентификация владельца (единственный аккаунт, создаётся через CLI), публичная витрина с опциональной приватностью экземпляров, дневной лимит AI-вызовов для защиты от перерасхода (Шаг 5)
- Полнотекстовый поиск и предупреждение о дубликатах при создании похожего издания (Шаг 6)
- PWA — установка на телефон, офлайн-страница, service worker с кэшированием статики (Шаг 7)
- Деплой на VPS (Docker Compose + Caddy, автоматический HTTPS), `book.glorden.ru` (Шаг 8)
